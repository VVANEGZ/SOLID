# OCP — ejemplo bueno de Justin

Bebida y Descuento permiten extender las variantes sin editar el algoritmo de Caja. App demuestra venta con descuento navideño y sin descuento.

Desde esta carpeta:
```powershell
javac -encoding UTF-8 -d bin src/*.java
java -cp bin App
```

Con agua de 20, refresco de 25 y cerveza de 30, el subtotal es 92.50. Navidad: total 83.25 y cambio 16.75. Sin descuento: total 92.50 y cambio 7.50. Puede haber diferencias de representación decimal por double.
